# Auto Ad Skipper

Расширение для Chromium-браузеров, которое делает видеорекламу в онлайн-плеерах незаметной. Запустил серию — и просто ждёшь: реклама идёт без звука, а кнопка «Пропустить» нажимается сама, как только становится активной. Работает и с цепочками из 2–3 роликов подряд.

> Репозиторий стоит переименовать (Settings → General → Rename), например в `auto-ad-skipper` или `skip-ads` — GitHub автоматически редиректит старые ссылки.

## Что оно делает

- **Мут с первой секунды.** Как только распознана реклама, звук глушится в два слоя: мут всей вкладки (гарантия — ловит даже звук из фреймов, которые не удалось классифицировать) плюс мут самих `<video>/<audio>` в рекламном фрейме (срабатывает мгновенно, без задержки на сообщения). После рекламы громкость контента возвращается ровно к прежней. Если вкладку замутил ты сам — расширение её никогда не размутит.
- **Автоклик по «Пропустить».** Движок следит за кнопкой пропуска, честно ждёт окончания таймера («Пропустить через 5 сек») и кликает в тот момент, когда кнопка реально становится кликабельной: не disabled, видима, не перекрыта оверлеем. Понимает русский, украинский и английский текст кнопок.
- **Цепочки роликов.** После пропуска движок остаётся «горячим» и ловит следующий ролик — все 2–3 подряд уходят сами.
- **Защита от попандеров.** Перед синтетическим кликом на 1.8 секунды блокируется `window.open` страницы — клик-хайджек не откроет мусорную вкладку.
- **Универсальность.** Никакого списка сайтов: эвристики трёх ярусов работают на любом сайте (домены рекламных сетей → селекторы известных рекламных движков IMA/VAST, video.js, JW Player → анализ текста кнопок). Для упрямых сайтов есть механизм адаптеров (`ADAPTERS` в `content/patterns.js`).
- **Безопасность от ложных срабатываний.** Голая кнопка «Skip» на обычной странице ничего не триггерит: для мута и клика нужны подтверждающие сигналы (видео + бейдж «Реклама» / таймер / рекламный контейнер). Кнопки «Пропустить заставку/интро/титры» в стоп-листе — их расширение не трогает никогда.

## Установка

1. Скачай/склонируй репозиторий.
2. Открой `chrome://extensions` (в Яндекс.Браузере — `browser://extensions`, в Edge — `edge://extensions`).
3. Включи **Режим разработчика** (переключатель в углу).
4. Нажми **«Загрузить распакованное расширение»** и выбери папку репозитория (где лежит `manifest.json`).

Требуется Chromium 111+ (Chrome, Edge, Яндекс.Браузер, Opera, Brave — любой свежий).

## Использование

Просто смотри. На иконке расширения растёт зелёный счётчик пропущенных реклам на вкладке. В попапе:

| Настройка | Что делает |
|---|---|
| Главный тумблер | Вкл/выкл везде |
| «Этот сайт» | Отключить только на текущем сайте |
| Проматывать рекламный ролик в конец | Экспериментально: `currentTime → конец` + скорость ×16. Выключено по умолчанию — на некоторых плеерах ломает загрузку |
| Блокировать попандеры при автоклике | Заслонка `window.open` вокруг наших кликов |
| Заглушение рекламы | «Вкладка + видео» (по умолчанию) / только видео / не заглушать |
| Отладочные логи | `console.debug` с пометкой `[AAS]` в каждом фрейме — полезно, если сайт не поддаётся |

## Как это устроено

> Если собираешься дорабатывать проект — читай [DEVELOPMENT.md](DEVELOPMENT.md): там подробный разбор архитектуры, отладка на реальных сайтах, разбор граблей и список задач на будущее.

- `content/engine.js` — движок в каждом фрейме (включая вложенные кросс-доменные iframe плееров): MutationObserver + машина состояний `IDLE → AD_ACTIVE → SKIP_WAIT → RESTORE`. В покое на обычных страницах почти ничего не делает (только наблюдатель, без интервалов).
- `content/patterns.js` — данные эвристик: домены рекламных сетей, селекторы рекламных движков, текстовые паттерны (с поправкой на то, что `\b` в JS-регэкспах не дружит с кириллицей), адаптеры.
- `content/page-guard.js` — единственный кусок в MAIN-мире страницы: подмена `window.open` на время нашего клика.
- `background.js` — сервис-воркер: мут вкладки (с проверкой, кто её замутил), бейдж, статистика; переживает перезапуски MV3 через `storage.session`.
- `popup/` — интерфейс настроек.

## Ограничения

- Кнопки внутри **closed** shadow DOM не видны (открытые — обходятся).
- Клики синтетические (не «trusted») — подавляющее большинство плееров их принимает; режим с `chrome.debugger` сознательно не реализован.
- На YouTube движок тоже сработает по IMA-паттернам — это безвредно, но для YouTube существуют более специализированные решения.
- Сайт с совсем нестандартной кнопкой: включи отладочные логи, посмотри, что пишет `[AAS]` (`no skip candidates` / `candidate not clickable (…)`), и добавь адаптер в `ADAPTERS`:

```js
const ADAPTERS = {
  "example.org": {
    skipSelectors: [".my-skip-btn"],
    adSelectors: [".my-ad-overlay"],
  },
};
```

## Тесты

E2E-прогон в headless Chromium с фикстурой, симулирующей плеер с двумя рекламами подряд (IMA-стиль и текстовый countdown), ловушкой-попандером и декоями:

```bash
NODE_PATH=/opt/node22/lib/node_modules node test/run-e2e.cjs   # где Playwright установлен глобально
```

Проверяется: обе рекламы пропущены, мут ≤ 800 мс, ноль кликов до конца countdown, ноль попандеров, звук восстановлен, декои («Пропустить заставку», «Skip» в форме) не тронуты, контентное видео не замучено, попап рендерится и показывает статистику.

Флаги: `--serve-only` — поднять фикстуру для ручного просмотра; `AAS_HEADFUL=1` (+ `xvfb-run -a`) — если headless-запуск с расширением недоступен; `AAS_DEBUG=1 AAS_VERBOSE=1` — логи движка в вывод.

**Ручной чеклист** после изменений:

1. Фикстура глазами: `node test/run-e2e.cjs --serve-only`, открыть URL — обе рекламы уходят беззвучно.
2. Реальный сайт: пре-ролл глохнет мгновенно, скип по концу таймера, цепочка уходит целиком, громкость контента вернулась, бейдж растёт.
3. Отключение на сайте и глобальный тумблер переживают перезагрузку страницы.
4. Обычные сайты (новости, формы с «Skip»): ни мута, ни кликов, ни ошибок в консоли.
5. Замутить вкладку руками → после рекламы она остаётся замученной.

Иконки перегенерируются командой `node tools/gen-icons.cjs`.

## Дисклеймер

Инструмент для личного пользования — как любой блокировщик рекламы. Отдельные сайты могут не любить блокировку рекламы; используешь на свой страх и риск.
